## [0.3.0](https://github.com/leptoskit/leptoskit/releases/tag/v0.3.0)

### Features

#### leptoskit_plugin_maps: map sessions and Map surface

`leptoskit_plugin_maps` creates host-owned map sessions, sets camera and a bounded marker list, and binds them to the `Map` element. User location and shapes remain later scope. Guests enable `guest` and reuse `guest::Maps`.
