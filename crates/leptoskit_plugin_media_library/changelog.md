## [0.3.0](https://github.com/leptoskit/leptoskit/releases/tag/v0.3.0)

### Features

#### leptoskit_plugin_media_library: bounded list and save

`leptoskit_plugin_media_library` queries photo-library authorization, lists up to 64 assets, and saves an app-owned file URI into the system library. Change observation and albums remain later scope. Guests enable `guest` and reuse `guest::MediaLibrary`.
