# Hold an organisation's own spend cap to its plan's cap

An organisation's own spend cap could only be set up to the cap of the plan it was on at the time. When the organisation later moved to a plan with a lower cap, its own cap stayed as it was, so usage was allowed past the new plan's cap. Now, when a plan change moves an organisation to a plan whose cap is lower than its own cap, the own cap comes down to that plan's cap. An own cap that already fits is left as it is, whichever way the organisation moves.
