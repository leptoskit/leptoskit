`lk cloud` manages an environment's variables, secrets, domains, deployments, rollback and database, publishes to stores from the cloud with `lk cloud publish`, and shows usage. A CI token from `LEPTOSKIT_CLOUD_TOKEN` now goes only to the hosted cloud or to an origin named by `--url` or `LEPTOSKIT_CLOUD_URL`.
