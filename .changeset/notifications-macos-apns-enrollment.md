The `native` module's enrollment covers macOS: a generated macOS app with `[native.macos] aps-environment` set enrolls its APNs device token through the same `enroll`, `reconcile`, and `disable` calls as iOS and Android — the platform stays a transport choice, the token kind the host answers names the provider kind, and nothing forks beyond it. Docs and error text name all three platforms now.
