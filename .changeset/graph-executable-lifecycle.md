# Recover independent application instances

Connect the graph host installer to immutable executable releases, separate candidate ports, process-bound readiness, selected route promotion, boot enablement, retirement and rollback. Preserve unselected application instances and route bindings during a docs-only release. Record derived process and edge inputs before activation and reject later substitutions. Recovery keeps ownership until old processes and routes are ready, and tolerates an edge unit that was never installed. The CLI still requires the pending checked service-capture integration and real Linux acceptance before enabling executable releases.
