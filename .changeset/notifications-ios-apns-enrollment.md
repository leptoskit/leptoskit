iOS push enrollment: the `native` module, the client half of APNs behind the feature of the same name. From an explicit gesture the app requests notification permission through the notifications plugin's guest API and calls `enroll`, which registers for remote notifications, waits the host's bounded answer, and registers the device token as the signed-in person's typed `PushCredential::Apns` — the identity read from the app's forwarded session, never from an argument, and no service token or session copy anywhere. `reconcile` runs on launch without prompting: it reads the broker's snapshot and re-registers the token the OS already holds, answering the same endpoint id for a rotated destination, so refreshes never spend the per-person endpoint bound. `disable` revokes while still authenticated with the browser module's stable endpoint-derived idempotency key, so a retried sign-out replays its receipt, and never touches OS state. The OS's refusal surfaces as a typed error, silence as a bounded "no token yet", and a cancelled wait keeps the callback readable. iOS only — Android's FCM acquisition and the macOS wiring are later work — with no server dependencies in the guest feature tree.
