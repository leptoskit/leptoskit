# LK Pod wire format

Portable little-endian TLV codec for RPC (`application/vnd.leptoskit.rpc.v1+bin`), parked for evaluation. Structs carry a `u16` layout version. Language runtimes live under `packages/leptoskit-pod-*`. This branch does not switch the server off JSON.
