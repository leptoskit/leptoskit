# `@leptoskit/pod`

LK Pod is leptoskit’s portable little-endian TLV wire format for RPC and live frames.

- Content-Type: `application/vnd.leptoskit.rpc.v1+bin`
- Envelope magic: `LK01`

## Install

```bash
npm install @leptoskit/pod
```

## Test

```bash
npm test
```

Conformance vectors: `crates/leptoskit_pod/conformance/vectors.json`. See [adding a Pod language](../../docs/src/rpc/adding-a-pod-language.md).
