# Platform-Specific Features Research Audit

Comprehensive inventory of native OS and browser capabilities across mobile (iOS, iPadOS, Android), wearables (watchOS, Wear OS), desktop (macOS, Windows, Linux), and browser extensions (Chrome, Edge, Brave, Opera, Arc, Vivaldi, Firefox, Safari), mapped to LeptosKit APIs.

## 1. Core Cross-Platform Targeting Seam

- `leptoskit::target` (`crates/leptoskit_native/src/target.rs`):
  - `TargetPlatform` (14 variants covering web, extension, iOS, Android, macOS, Windows, Linux, HarmonyOS, Wear OS, watchOS, Quest, TUI, server, shared).
  - `PlatformSwitch<T>` for exact-platform -> family -> Apple/native -> default resolution.
  - `on_ios`, `on_android`, `on_mobile`, `on_macos`, `on_windows`, `on_linux`, `on_desktop`, `on_apple`, `on_web`, `on_extension`, `on_watch`, `when`.
  - `PlatformCapabilities` / `Capability` / `CapabilitySupport` for honest upfront capability checks.
  - `with_platform` scoped override for deterministic cross-platform tests.
- `leptoskit_build::platforms()` + `leptoskit::platform_module!` supports all 12 app platform features (`web`, `ios`, `android`, `macos`, `windows`, `linux`, `harmonyos`, `wearos`, `watchos`, `quest`, `tui`, `extension`).

## 2. iOS & iPadOS Native Features

| Feature                                                                                                                 | Apple API                                                               | LeptosKit Surface                                            | Notes                                                                                                                     |

| Home Screen widgets                                                                                                     | WidgetKit (`systemSmall/Medium/Large/ExtraLarge`)                       | `leptoskit_plugin_home_widgets`                              | Snapshots, timelines, interactive actions; app owns SwiftUI Widget Extension target                                       |
| Lock Screen widgets                                                                                                     | WidgetKit (`accessoryCircular/Rectangular/Inline`)                      | `leptoskit_plugin_home_widgets`                              | Modeled via `WidgetFamily`                                                                                                |
| Control Center controls                                                                                                 | WidgetKit `ControlWidget` (iOS 18+)                                     | `leptoskit_plugin_home_widgets`                              | `ControlCenterControl` toggle/button descriptors                                                                          |
| Live Activities & Dynamic Island                                                                                        | ActivityKit (`Compact`, `Minimal`, `Expanded`)                          | `leptoskit_plugin_live_activities`                           | Activity lifecycle, push tokens, Dynamic Island regions, stale/relevance schedule                                         |
| App Intents / Siri Shortcuts                                                                                            | `AppIntents` framework                                                  | `leptoskit_plugin_app_shortcuts`                             | `AppIntentDefinition` + quick actions                                                                                     |
| Spotlight indexing                                                                                                      | `CoreSpotlight` (`CSSearchableItem`)                                    | `leptoskit_plugin_app_shortcuts`                             | `SpotlightItem`                                                                                                           |
| Handoff / Continuity                                                                                                    | `NSUserActivity`                                                        | `leptoskit_plugin_app_shortcuts`                             | `UserActivity`                                                                                                            |
| Share / Action Extensions                                                                                               | `UIActivityViewController` (out) / Share Extension (in)                 | `leptoskit_plugin_sharing`, `leptoskit_plugin_app_shortcuts` | Outbound sheet + `IncomingShare` model                                                                                    |
| Sheet detents, status bar, multi-scene, Pencil                                                                          | `UISheetPresentationController`, `UIWindowScene`, `UIPencilInteraction` | `leptoskit_plugin_app_shortcuts::MobileChrome`               | Portable descriptors for host integration                                                                                 |
| HealthKit, LocalAuth, Secure Enclave, Passkeys, NFC, ATT, StoreReview, Camera, Maps, Live Photo, Haptics, Speech, Video | Apple system frameworks                                                 | Dedicated `leptoskit_plugin_*` crates                        | Existing auto-registered plugins                                                                                          |
