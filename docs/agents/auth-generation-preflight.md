# Auth generation preflight

The generator parses both selected crate roots before writing any screens, features, routes, or configuration. It preserves existing out-of-line module declarations and refuses inline modules, explicit or conditional path overrides, duplicate declarations, malformed Rust, and a server module directory that would conflict with `sign_in.rs`. `--force` only replaces template files; it does not override module ownership.

Call detection is a conservative syntax check. Direct `auth::provide()` and `auth::screens().gate(...)` calls suppress the root reminder; direct `sign_in::service(...)`, `sign_in::provider(...)`, and `auth::screens().navigate_with(...)` calls suppress their respective reminders. Comments, literals, function references, macro token streams, and ordinary `#[test]` or `#[cfg(test)]` bodies do not count. No macro expansion, name resolution, conditional compilation evaluation, or control-flow analysis is performed. A helper or alias may need manual review even when its runtime behavior is correct. A syntactically present call is not proof of startup, route mounting, identification, or database authorization.

Tests exercise unchanged-file refusal for both roots, conditional path overrides, preservation of declarations and comments across reruns, directory conflicts, incomplete syntax, function references, and missing UI gating. The existing router integration and generated-app journeys remain required full-CLI acceptance. This slice does not automate account ownership migration or close X06.

Validation evidence is retained by the audit orchestrator outside shared caches. Scoped generator tests use the production generator with a small harness; router generation and native renderer class validation are outside that harness. Full CLI tests, snapshots, normal publication checks, and generated-app runtime acceptance remain pending until a build slot is available.

The scoped harness passed 46 tests, with four router tests filtered out and one unrelated native-class test excluded from compilation. Clippy passed with the repository rules. Three tests were rerun against the previous generator and failed at the required assertions: module conflict refusal, preserving declarations with comments, and retaining guidance for function references. Formatting, metadata lock validation, docs and release checks passed. The changed generator and parser passed the readability check; checking the whole auth template directory also includes existing template complexity failures and is not a full-gate pass.
